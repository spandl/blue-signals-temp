# White label layout

## Components

- Workspace selector
- Help menu
- Account menu
- Branding placeholder for agency
- Main menu
- Application placeholder

![image.png](image%201.png)

### Workspace selector

- Displayed for all users
- Disabled if user has access to a single workspace
- On click: Shows list of all available workspaces

### Help menu

- On click: Shows a list of links to available help resources
    - Help with this page: Link to the documentation for the current page
    - Help Center: Link to the Help section home page
    - Support chat: Opens the chat widget

Note: Other links, such as submitting a feature request, are only available in the Help Center

### Account menu

- On click: Shows list of links to available account resources
    - Account settings
    - Billing
    - Log out

### Branding placeholder for agency

- By default: teamfluence logo
- Some subscriptions allow the upload of a custom logo

### Main menu

- Includes two sections: Signals (operational app) and Platform (app and process configurations)
- Each section contains a two-level menu
- The first level is expanded only if subpages exist and the user is within that section

### Application placeholder

- Slot for application
