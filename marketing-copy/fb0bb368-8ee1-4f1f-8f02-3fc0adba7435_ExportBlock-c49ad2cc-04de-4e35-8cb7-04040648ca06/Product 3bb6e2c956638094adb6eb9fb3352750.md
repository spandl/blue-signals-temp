# Product

## Goal of the product

The new version of Teamfluence will be optimized for agencies, allowing them to manage all LinkedIn operations on behalf of their customers. 

The ultimate success metric are qualified leads, which can be handed over to the client

- Leads that pass the an ICP match
- Leads that engage with the customer
- Clients that converted

## The user journey

An agency will perform following steps to provide their customers a list of qualified leds

1. Register all client profiles in the client account
2. Post content on behalf of the customer and track posts from influencers
3. Setup workflows and run leads through ICP tests.
4. Send connection requests to qualified leads and start a conversation through direct messages
5. Setup different smart lists and manually adjust these lists using a kanban-style interface
6. Export lists as CSV or push certain lists to an external CRM
7. Monitor and analyze post content that generated leads

## The available tools (modules)

### Signals

- Overview
    - Condensed view of key metrics and goals for all workspaces
- Content (Post tracker)
    - Find relevant LinkedIn content by entering influencer page URLs or keywords
    - Track relevant content (posts)
- People (Smart lists)
    - Create different types of list and manage them via a Kanban or table view interface
    - Use any ~~dimension~~attribute, like status, geography, etc
    - Configure scheduled tasks to export or sent a list to a customer
    - Option to export new leads on list to a CRM or notify via Slack
    - Manually enrich profiles with notes or tags, etc
    - Successful Content
        - See all content that collected signals from a person on a list
- Unified Inbox
    - Follow up on direct connection/DM responses on behalf the customer
    - Per-client/workspace **FAQ/knowledge base** upload.
    - AI drafts replies, low confidence → human presses send; high confidence → auto-send.

### Platform

An agency can perform the above tasks by using following product features

- Account configuration
    - Setup customer profiles
    - Configure granular access rights for agency users (which agency user can perform which tasks on behalf the customer profile)
    - Configure access rights for end-customer
- Workflows
    - Run ICP matches for people that have been sending signals
    - Send connection requests
    - Send direct messages
    - Enrich profiles
    - etc.
- Invite Management (Campaigns)
    - Send connection requests through workflows
    - Send connection requests through csv uploads or CRM imports
- Targets
    - Let agencies configure targets, such as amount of tracked posts, number of expected leads
    - Goal overview page to quickly identify if expectations are met
- Health
    - List of all accounts with indications if members are connected to LinkedIn
- Branding tool
    - Customize look of interface by uploading agency logo and adapt color scheme
    - Configure domain name
- ABM account matching
    - Upload lists of company profile pages to identify target accounts
    - Can be used for distinct/stricter ICP-matching profile in the workflow engine

## On-boarding

Some features are harder to set up than others. ICP definitions and workflows, combined with connection campaigns, are key to making Teamfluence work, but they can be difficult to understand when you’re just getting started.

As a high-quality product, we should offer a service to set up these sections initially, along with solid training and clear documentation. This initial setup could be packaged as a paid service offering ($$).

We should leverage our expertise with the software to give new customers a head start.

## Pricing

Two factors affect the price

- accounts
- credits for enrichment or AI features

The smallest entry-level package contains 10 accounts. Agencies can split them up among as many customers they want. Subscriptions have a generous amount of credits.

Both, accounts and credits can be added to the base subscription price; The entry price should not be lower than 599$US/month.

Additional accounts are 59$US/account, but cost will decrease with higher volumes. Pricing for additional credits must be evaluated.
